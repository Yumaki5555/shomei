# 署名掲示板

change.org と Voice（voice.charity）から、テーマごとのキーワードで署名運動を探し、
パブコメ掲示板と同じような一覧ページにまとめる仕組みです。
実行するたびに署名数を記録するので、「どれくらい増えているか」がわかります。

## 月2回の手順（このフォルダで実行）

```
python collect.py        ← ① 集める（署名数の記録も、このとき一緒に行います）
python review.py         ← ② 載せる署名を選ぶ（ブラウザが開きます）
python publish.py        ← ③ ページを作って公開
```

- ① は、キーワードの数によって数分〜数十分かかります。
- ② の画面で「載せる」「載せない」「☆おすすめにする」を押します。押すとすぐ保存されます。
  終わったら黒い画面で `Ctrl + C` を押して閉じます。
- ③ は「載せる」にした署名だけのスクショを撮ってから、ページを作ります。

※ ① と ② を同時に動かさないでください（同じファイルに書き込むため）。

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `collect.py` | 署名運動を探して `data.json` に「候補」として保存。持っている署名の今日の署名数を記録。終わった署名は「終了」にする |
| `review.py` | 候補を選ぶための自分用の画面 |
| `shots.py` | 「載せる」にした署名のスクショを撮る（`publish.py` が自動で呼びます） |
| `build.py` | 一覧ページ `docs/index.html` と、1件ごとのまとめページ `docs/p/` を作る |
| `post.py` | X投稿文 `posts.txt` と、ボタンで投稿できる `docs/posts.html` を作る |
| `publish.py` | 上の3つを順に動かして、GitHubに送る（公開） |
| `keywords.json` | テーマ・キーワード・タグの表。自由に編集OK |
| `config.json` | サイト名・公開アドレス・タグの色とハッシュタグ |
| `data.json` | 集めた署名の台帳（自動で書き換わります） |
| `state.json` | 「前回どこまで見たか」の記録（自動で書き換わります） |

## 署名の状態

| 状態 | 意味 | 公開ページ |
|---|---|---|
| 候補 | 見つかったばかり。まだ選んでいない | 出ない |
| 掲載 | 「載せる」を押したもの | 出る |
| 非掲載 | 「載せない」を押したもの。次から見つかっても候補に戻らない | 出ない |
| 終了 | 署名サイトで終了・成功したもの（自動で判定） | 出ない |

⭐おすすめ にした署名は、一覧のいちばん上に並び、X投稿文ページでも先頭に出ます。

## テーマ・キーワードを増やす

`keywords.json` を編集します。

```json
"テーマ名": {
  "keywords": ["検索したい言葉1", "検索したい言葉2"],
  "tag": "ページに表示するタグ名",
  "title_only": true
}
```

- `title_only` を `true` にすると、タイトルにその言葉が入っているものだけを候補にします
  （本文にちらっと出てくるだけの、関係ない署名が多いテーマ向け）。
- 新しいタグを作ったら、`config.json` の `tags` に色とハッシュタグも足してください（足さないと灰色で表示されます）。
- 新しく足したキーワードは、最初の1回だけ `python collect.py --full --theme テーマ名` で過去の分まで探せます。

## 便利なオプション

```
python collect.py --full          # 検索結果を最後のページまで全部見る（最初の1回用）
python collect.py --theme 民泊    # 特定のテーマだけ
python collect.py --dry-run       # 保存せずに、見つかったものを表示するだけ
python publish.py --no-push       # 公開せずに、手元でページを作るだけ
```

## 注意点

- change.org と Voice のどちらも、サイトの内部の仕組みを使って情報を読んでいます。
  サイト側の作りが変わると動かなくなることがあります。
- Voice は短い間にたくさん読みに行くと断られるため、1秒ずつ間をあけています。
- 署名数は「実行した日の人数」です。
