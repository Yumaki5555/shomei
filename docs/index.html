    署名ってどうするの？

    はじめての方へ。ネットの署名は、3つのステップで参加できます。

    1. 1

      気になる署名を探す

      上の「署名をさがす」で、キーワード・テーマ・地域を組み合わせて探せます。

    2. 2

      内容と発起人を確認する

      カードの「くわしく見る」や署名ページで、何を求める署名か、だれが始めたか（発起人）を確かめます。

    3. 3

      署名サイトで賛同する

      紫色の「署名ページを見る」を押すと、署名サイト（Voice または change.org）が開きます。内容に賛成できたら、そのサイトで署名します。

    署名したら「☐ 署名した」を押しておこう。カードに ✅ がついて、どれに署名したかがひと目でわかります。「署名済み（✅）の署名」で、隠したり、それだけ表示したりもできます。記録はこの端末のブラウザの中だけに残り、どこにも送られません。

    署名する前に確認してほしいこと

    • 掲載＝賛成・保証ではありませんこの掲示板に載っていても、署名の内容に賛成したり、保証したりするものではありません。
    • 発起人と内容を確かめてから署名をだれが、何を求めて始めた署名なのかを確認してから、ご自身で判断してください。
    • 署名数は「確認した日」の人数ですカードに確認した日を書いています。最新の人数は署名ページでご確認ください。
    • 支援金（お金）は任意です署名のあとに「お金で応援しませんか」という画面が出ることがありますが、払わなくても署名だけで参加できます。
    この掲示板にのせている署名について

    このページでは、change.org と Voice の2つの署名サイトをキーワードで検索し、その中から運営者が選んだ署名を載せています。内容を保証するものではありません。

    change.org の署名については、内容をよく確かめたうえで、ご自身で判断してください。

    カードの「概要」は、署名ページの本文の書き出しです。全文は署名ページでご確認ください。

    支援金（お金での応援）について

    どちらのサイトも、署名のあとに「お金で応援しませんか」という画面が出ることがあります。お金を払わなくても、署名だけで参加できます。支払い画面が出ても、そのまま閉じてかまいません。

    • Voice の「エール」は、署名を始めた人（発起人）に届きます（手数料を引いた額）。
    • change.org の支援金は、発起人ではなく change.org（運営会社）に支払われます。

    くわしくは 署名サイトの違い をご覧ください。

    「署名した」の記録について

    「☐ 署名した」を押すと、この端末のブラウザの中だけに記録されます（どこにも送られません）。

    別の端末や、閲覧履歴を消したあとには引き継がれません。

    署名サイトの違い（Voice と change.org）

    この掲示板の署名は、Voice と change.org の2つのサイトのものです。運営している会社や、支援金の行き先がちがいます。

    • 支援金（エール）は、発起人に届きます

    🌐 change.org

    • 支援金は、運営会社（change.org）に支払われます
